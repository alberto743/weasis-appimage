# Third-party license texts

Standard texts of the licenses that apply to software bundled in the AppImage, reproduced unchanged
from the SPDX license list for notice purposes. They are not licenses of this repository.

The BSD, MIT and Zlib texts are the generic forms: the copyright line of each project is given by
that project, and is listed in `THIRD-PARTY-NOTICES.md` and in the notice files collected from the
upstream package. Which component uses which license is stated in `THIRD-PARTY-NOTICES.md`.
