# Security policy

This repository only repackages released Weasis builds; vulnerabilities in Weasis itself belong to
the [upstream project](https://github.com/nroduit/Weasis).

Report problems specific to this packaging (a tampered or mismatching release asset, a wrong
checksum or attestation, a workflow weakness) by opening a private security advisory in this
repository, or an issue if advisories are not available. Please include the release tag and the
asset name.
